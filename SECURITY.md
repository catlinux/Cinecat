# Seguridad / Security

## Español

Cinecat servirá contenido personal y podrá exponerse a internet, así que la seguridad es un requisito desde el diseño. Los principios están en [arquitectura](docs/es/arquitectura.md).

**Versiones con soporte:** todavía no hay versiones con código.

**Cómo informar de una vulnerabilidad:** no abras un *issue* público. Usa el aviso privado de seguridad de GitHub (*Security → Report a vulnerability*) en este repositorio. Responderá el mantenedor, **Catlinux**.

**Qué incluir:** descripción, pasos para reproducirlo, versión afectada y posible impacto.

## English

Cinecat will serve personal content and may be exposed to the internet, so security is a design requirement. Principles are in [architecture](docs/en/architecture.md).

**Supported versions:** there are no versions with code yet.

**How to report a vulnerability:** do not open a public issue. Use GitHub's private security advisory (*Security → Report a vulnerability*) on this repository. The maintainer, **Catlinux**, will answer.

**What to include:** description, reproduction steps, affected version and potential impact.
